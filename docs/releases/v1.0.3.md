## 新增功能

- 新增桌面收纳原位恢复：收纳文件和文件夹时记录桌面图标位置，恢复、撤销和退出恢复时自动放回原位置；跨分类移动和重启后继续保留位置记录。

## 优化与调整

- 将桌面框架由 Electron 替换为 Rust + Tauri 2，使用 Windows WebView2 显示原有 React 界面，保留任务、便签、项目、剪贴板、桌面收纳、截图贴图、工具箱、局域网传输和桌面小组件等功能。
- 将工作区保存、剪贴板监听、任务提醒、专注完成、备份、快捷键和托盘生命周期迁移到 Rust 后台，主窗口收起后继续提供相应服务。
- 更新应用图标，统一侧栏、程序、窗口、托盘、通知、安装包和开始菜单的蓝色收纳托盘与任务卡片形象。
- 在“设置 → 更新”中展示框架变更、数据位置与升级提示，并提供本版本的完整说明入口。

## 破坏性变更

- 默认数据目录调整为 `DustDesk.exe` 同级的 `Data` 文件夹，开发模式使用项目根目录下的 `Data`。旧 `%AppData%\DustDesk.Next\Data` 不会自动覆盖新目录。升级前请在旧版保存编辑内容并导出工作区备份，再通过新版“设置 → 数据与备份”恢复；旧浏览器中尚未保存的草稿不会自动导入。
- 程序目录需要写入权限。移动绿色版时请一起移动 `Data`，删除或卸载前先备份该目录。回退到 v1.0.2 或 v1.0.1 时请使用旧版与升级前的备份，保留新版 `Data`，避免混用数据目录；这两个历史版本继续保留原框架。

## 已知问题

- Windows 桌面开启“自动排列图标”时，恢复后的排列由系统决定；本应用不会更改该设置。旧版本已收纳且没有记录位置的项目，无法追溯原始坐标。
- 局域网传输仍以同一 IPv4 局域网内的 DustDesk 设备为目标；跨网段、IPv6 和公网直连不在当前支持范围内。

## 下载与安装

- `DustDesk-1.0.3-x64.exe`：Windows 10/11 x64 安装包。
- `DustDesk-1.0.3-x64-green.zip`：Windows 10/11 x64 免安装绿色版，解压后运行 `DustDesk.exe`，数据保存在程序同级的 `Data` 文件夹。
- `SHA256SUMS.txt`：以上文件的 SHA-256 校验值。
- 运行需要 Microsoft Edge WebView2 运行时，无需安装 Node.js 或 Rust；缺少 WebView2 时，安装包会引导安装。
