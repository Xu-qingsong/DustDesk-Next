## Bug 修复

- 修复概览快速记录未失焦便退出时内容丢失，以及跨窗口更新覆盖编辑内容的问题；输入现在延迟保存，正常退出前会提交最后的修改。
- 修复中文输入法组词期间按 Enter 提前创建任务或子事项、保存快速记录，以及按 Esc 清空搜索或隐藏记录窗口的问题。
- 修复空白结束日期的日历忽略阶段开始日期、打开到当前月份的问题；现在从允许的开始日期打开，并保留日期范围限制。
- 修复任务设置提醒日期后，任务从当前日期列表移出并导致编辑器中断的问题；正在编辑的任务会保持可操作，完成编辑后仍可确认或清除提醒。
- 修复任务概览和任务页按创建时间统计提醒任务、完成任务的问题；现在按本地日历日期和实际完成时间统计。
- 修复侧栏隐藏当前页面后仍停留在不可见页面的问题；现在自动切换到第一个可见页面或设置页。
- 修复剪贴板“监听设置”入口无法直达对应设置区域的问题。

## 新增功能

- 新增文本工具箱，支持 JSON 格式化、URL 和 Base64 编解码、正则测试、文本对比、去重、排序和统计，切换工具时保留参数草稿。
- 新增批量图片工具箱，支持静态 PNG、JPG、WebP 的格式转换、尺寸调整、水印和实时预览；单张直接保存图片，多张导出 ZIP，保留原图并避免覆盖同名文件。
- 新增头像裁剪和证件照尺寸预设，支持方形及透明圆形头像、独立构图，以及按 300 DPI 输出常用证件照尺寸。
- 新增 DustDesk 电脑间局域网传输，支持设备配对、加密传输、暂停、取消和中断续传。
- 新增侧栏菜单设置，可独立显示、隐藏和排序工具箱入口。

## 优化与调整

- 优化工作区跨窗口同步、延迟保存、失败重试和退出前强制提交，减少过期快照覆盖新编辑的风险。
- 优化工具箱、截图、小组件和图片资源的按需加载，离开页面时取消无效 Worker 任务并释放订阅资源。
- 优化任务、便签、项目、剪贴板等页面的数据兼容和新记录字段初始化，旧工作区可继续读取并自动补全字段。
- 优化剪贴板图片加载，列表和小组件按需读取缩略图，预览时读取原图，复制时保留原始图片数据。
- 统一下拉选择、日期时间、颜色和数字等表单控件，适配明暗主题、键盘操作与中文输入法；数字草稿不会被后台同步覆盖。

## 已知问题

- 局域网传输目前仅支持 IPv4；自动发现受网络或防火墙限制时，可手动输入对方页面显示的 IP 和 HTTPS 端口，并允许对应的网络访问。
