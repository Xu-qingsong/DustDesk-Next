## Bug 修复

- 修复项目页面的固定按钮与桌面小组件列表状态不同步的问题；项目、便签和收纳组合的显示、隐藏及关闭操作现在会同步更新各入口，取消固定时保留窗口位置和设置。
- 修复系统检测页的指标显示开关未作用于监控小组件的问题，桌面监控现在遵循相同的 CPU、内存、网络、磁盘、延迟和运行时长设置。
- 修复桌面小组件启用屏幕边缘吸附后没有立即生效的问题，拖动时按屏幕工作区吸附，并保存最终位置；兼容多屏坐标和旧版启动器设置。
- 修复部分应用、快捷方式和文件夹图标加载失败或识别错误的问题；`.lnk` 快捷方式按正确类型展示，图标提取失败时保留可见的类型图标，并允许后续重试。
- 修复截图选区二次调整未生效、首次标注时选区和工具栏重绘、箭头端部露出线段等问题，并减少首次使用工具时的延迟。
- 修复链接、任务等小组件列表行随窗口高度被拉伸的问题，长内容保持在窗口内，较多条目使用滚动展示。
- 修复工作区保存或备份失败时可能破坏恢复副本的问题；损坏数据、读写失败及新版工作区现在提供明确反馈，失败操作可重试。
- 修复跨磁盘整理中源目录清理失败时删除完整目标副本的问题；复制失败只清理本次临时目录，清理源文件失败时保留完整目标副本。
- 修复剪贴板图片重复编码、便签背景恢复和文件搜索取消后的异步处理问题，避免无效任务覆盖新的结果。
- 修复关于、反馈和更新检查链接指向其他仓库的问题，统一使用本项目 `Xu-qingsong/DustDesk-Next` 的 GitHub 页面与正式版本。
- 修复侧栏版本号固定显示 `v1.0.0` 的问题，界面版本随构建包版本同步更新。

## 新增功能

- 新增项目阶段甘特图，支持适应、日、周、月刻度、阶段日期与进度展示、今日标记，以及点击阶段打开编辑弹窗。
- 新增共用截图对象编辑器，区域截图、应用内编辑和贴图重新编辑使用统一的标注与输出逻辑；支持实时绘制预览、椭圆、高亮、可再次编辑的文字、序号、遮盖工具、样式调整及最多 100 步撤销重做。
- 新增实时桌面区域框选流程，支持移动选区、八方向调整、尺寸显示和浮动工具栏；确认操作后仅捕获选中区域。
- 新增截图画布缩放、100% 查看、空格拖动画布、裁剪预览，以及拖入图片和剪贴板图片导入；复制、PNG/JPG 保存和贴图使用编辑后的合成结果。
- 新增独立贴图控制，支持滚轮缩放、透明度、置顶、锁定、鼠标穿透、复制、保存和重新编辑；托盘可统一显示、隐藏、关闭贴图并恢复鼠标操作。
- 新增小组件列表中的独立项目、便签和收纳组合入口，以及常规小组件和收纳组合窗口内的隐藏按钮。
- 新增版本发布规范，后续未指定版本时默认递增补丁号，版本介绍统一使用分类标题与条目说明。

## 优化与调整

- 调整桌面收纳页布局，桌面项目使用带图标和名称的宫格；收纳规则、分类管理使用弹窗，文件收纳分类列表由右上角悬浮按钮展开。
- 调整项目阶段添加和编辑交互为弹窗，保留子事项；甘特图横向滚动时固定阶段名称。
- 优化图标异步加载、请求合并、缓存和失败容错，限制同时提取数量，避免大量项目加载时阻塞界面。
- 优化截图预览绘制调度；图片处理与编码使用 Worker，过期异步结果按文档修订校验，不覆盖新编辑内容。
- 调整截图编辑输出时机，编辑模式捕获原图时不自动导出、复制或加入剪贴板历史；确认输出时再处理编辑结果。
- 调整更新流程为手动“检查更新”：发现本仓库新正式版本后展示版本号和更新内容，确认后打开发布页面下载。

## 破坏性变更

- 本次正式版使用 Electron 主线，应用默认数据目录为 `%AppData%\DustDesk.Next\Data`。升级前请保留旧版工作区及备份，切勿用旧版程序覆盖新版工作区。
- 工作区格式升级到版本 3，剪贴板图片迁移至 `ClipboardImages`，工作区保存图片引用。升级前请使用应用的备份功能保留数据；旧版应用不能直接读取升级后的工作区，回退到 v1.0.0 时需使用升级前的备份。
- 更新入口不再自动下载或安装更新；确认更新后从 GitHub Release 下载本版本安装包或免安装绿色版。
- 贴图只在当前运行期间保留，退出应用后清理贴图会话；需要长期保留的图片请使用“保存”导出。

## 已知问题

- 区域截图支持在各屏幕分别选择，本版本不支持跨屏拼接选区。
- 跨磁盘整理文件夹时，若源文件被占用导致清理失败，完整目标副本会保留，但可能尚未登记到收纳分类列表；请按错误提示的源、目标路径手动定位，解除占用并核对文件后再处理，避免重复整理。

## 下载与安装

- `DustDesk-1.0.1-x64.exe`：Windows 10/11 x64 安装包，可选择安装目录。
- `DustDesk-1.0.1-x64-green.zip`：Windows 10/11 x64 免安装绿色版，解压后运行 `DustDesk.exe`；请保留全部附带文件。数据继续保存在 `%AppData%\DustDesk.Next\Data`。
- `SHA256SUMS.txt`：安装包和绿色 ZIP 的 SHA-256 校验值。
