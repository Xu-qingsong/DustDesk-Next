# 工具箱与局域网传输

三个模块分别位于侧栏的“文本工具箱”“图片工具箱”和“局域网传输”。切换页面保留当前运行期间的输入和任务，不自动复制、导出或上传输入内容。

三个工具入口首次默认隐藏，可在“设置 → 侧栏菜单”中开启，开启后默认排在侧栏底部。菜单可拖动排序、上下移动或隐藏；修改立即保存，重启后保留。恢复默认会重新隐藏这三个入口；已保存的显示选择不会在升级时被覆盖。隐藏只影响侧栏入口，设置入口始终可用，截图快捷键等功能仍可使用。

## 文本工具箱

- JSON 格式化与压缩、URL 和 UTF-8 Base64 编解码、正则测试、按行对比、去重、自然排序、统计和大小写转换。
- 输入变化后延迟 300 毫秒处理，中文输入法组词期间不执行。处理在独立 Worker 中运行，新输入取消旧任务；正则超过 1 秒、其他处理超过 5 秒终止并提示重试。
- 切换工具保留对比、正则和行处理的参数草稿；仅当前工具的参数参与处理，空输入不会因其他工具的草稿而触发错误。拖动任意一侧文本框，两侧高度同步。
- 每份输入最多 10 MiB；正则最多显示 10000 项，差异预览最多显示 3000 行，复制和导出保留完整结果。差异超过 2000 步时提示缩小范围，避免耗尽内存。
- 复制和导出结果最多 40 MiB，可容纳编码或格式化后增大的结果；导出使用 UTF-8。输入不写入工作区；明确复制后的内容仍遵循现有剪贴板监听设置。

## 图片工具箱

- 导入、拖入或粘贴静态 PNG/JPG/WebP，提供缩略图、前后预览、格式转换、质量、比例和尺寸调整，以及文字或图片水印。
- 各导入入口共用缩略图流程；修改处理参数后清除旧预览及输出尺寸、大小，重新处理后显示当前结果。
- 图片列表支持逐张勾选、全选和删除选中；批量删除使用应用内确认窗口，默认聚焦取消。删除仅移除列表项并释放缩略图和文件授权，保留原始及已导出文件；导入或处理期间禁止选择和删除。
- 默认保持原格式和尺寸，不放大小图，不加水印；JPG/WebP 有损质量为 85。JPG 默认白色背景，PNG 无损编码不受质量滑块影响。同格式、实际尺寸不变且无水印时，重新编码未变小会保留原始字节（包括原有元数据）；其他输出重新编码，不携带原有元数据。列表显示减小／增大比例或保留原图；转换、缩放及水印结果仍可能变大。需要更小文件可选择 WebP/JPG 或缩小尺寸。
- 显式选择 PNG 或保持原格式且全部已识别为 PNG 时隐藏有损质量和 JPG 背景；WebP 隐藏 JPG 背景。混合批次的质量仅作用于 JPG/WebP，背景仅作用于 JPG。尺寸调整时才显示放大选项，所有尺寸、比例及水印数值使用普通输入框，失焦或 Enter 后校验。
- 单图最多 100 MiB、6400 万像素；不支持 APNG 和动画 WebP。Worker 逐张解码、处理和编码，单图处理超过 60 秒提示失败。
- 导出按本次选择数量处理：单张使用保存窗口直接保存 PNG/JPG/WebP 图片，多张保存一个 ZIP 压缩包，包内图片命名为“原名-处理后”，同名加序号。原格式按实际图片内容识别；保存名称与选定格式匹配。目标文件已有同名时自动加序号，不覆盖源文件或已有输出。
- 导出期间使用临时目录，图片和 ZIP 完整写入后再发布最终文件并清理临时内容。成功项保留，失败项可重试；取消停止后续处理并等待已提交写入收尾，多图操作保留含成功图片的 ZIP；没有成功图片时不创建空文件或空压缩包。ZIP 保存失败会明确提示，相关图片可重试；单个失败项重试时直接保存图片。

## 局域网传输

- 两台电脑均运行 DustDesk 并开启局域网服务。本轮只支持局域网 IPv4，自动发现使用 UDP 45892，文件流使用页面显示的 HTTPS 端口；发现受阻时可手动输入对方 IP 和端口。
- 已配对设备通过 HTTPS 定期保活，手动连接不依赖 UDP 广播持续在线。连接中断后设备会在约 20 秒内从列表隐藏；服务关闭时停止保活，恢复联系后重新显示设备，证书指纹变化仍须重新连接并核对配对码。
- HTTPS 使用本地生成的设备证书。首次配对必须在双方核对六位配对码；后续固定证书指纹，身份改变须重新确认。每次接收仍有独立确认，不自动接收文件或文本。
- 设备发现更新已配对设备的地址和端口时保留其固定指纹，心跳使用更新后的端点；指纹不同的广播不覆盖原配对。传输与续传连接同时核对原设备 ID 和指纹。配对确认受当前服务和任务生命周期约束，关闭服务或暂停／取消任务后不接受迟到的确认。
- 默认接收到系统下载目录下的 `DustDesk`，可选择其他位置。接收批次创建 `DustDesk-接收-*` 独立目录，保留文件夹层级和空目录；同名文件加序号。
- 一次最多 10000 个文件和目录。拒绝符号链接、越界路径、Windows 保留名称和特殊文件；传输只复制源文件，使用流式读取与背压，不将完整大文件读入内存。
- 未完成内容位于接收批次的 `.dustdesk-part-*` 目录，只有 SHA-256 校验通过的文件才发布为正式文件。请通过任务的继续或清理按钮处理临时目录，避免手动改动续传文件。
- 文件任务在网络中断或退出后保留。双方重启后，发送方选择继续，接收方重新确认；端口发生变化时，重新发现设备或手动连接页面显示的新端口。恢复前验证源文件和已接收前缀，源文件变化需重新发送。
- 暂停保留临时文件；取消及清理移除未完成文件，保留已完成的普通文件。文本仅在本次运行期间保留，接收后自行复制或保存。
- 发送和继续在提交任务后返回，准备、接收确认及传输进度由任务列表显示；传输期间可继续编辑发送内容，当前仍有发送任务运行时禁止重复提交。暂停、取消、删除和退出仍等待传输收尾。
- “清理已结束记录”只处理已完成和已取消的任务；暂停和失败任务可继续，单独点击“删除未完成任务”并确认后才移除任务和续传临时文件。清理或移除记录使用默认聚焦取消的应用内确认框；已接收文件保留，文本记录移除前需自行复制或保存。
- 设备身份、开启状态、可信指纹和文件续传清单位于 Electron `userData/LanTransfers`，与工作区 JSON、工作区备份分开。私钥不进入工作区备份；绿色版也使用当前用户的数据目录。

## 开发接口与验证

- 渲染层通过类型化 `dustdesk.toolbox` API 选择和登记文件，使用资产 ID 读取图片；Electron `webUtils.getPathForFile` 仅通过 preload 提供拖放文件路径。工具箱 IPC 仅允许主窗口调用。
- 图片和文本 Worker 与截图编辑器独立。主进程管理文件授权、输出、网络服务、确认弹窗及续传状态；文件内容和私钥不进入网络发现广播。
- `npm run test:toolbox:silent`：文本、图片与双端加密传输单元测试及真实 Worker 无窗口界面测试。
- `npm run e2e:toolbox`：先在隔离的真实 Electron 实例中验证粘贴缩略图、重复导入互斥、参数失效、失败重试，以及保存窗口、读取、Worker 和写入阶段的取消；验证单张 PNG/JPG/WebP 直接保存、多图 ZIP 内容、部分成功及压缩包保存失败后重试。再用两个隔离实例验证原生文件拖入、剪贴板边界、批量图片导出、HTTPS 配对、文件夹及文本、托盘接收和正常退出。工作流回归还验证工具参数隔离、图片设置显示、传输期间编辑、记录清理与删除确认，以及产生真实部分文件后双端退出、重启和续传的 SHA-256。确认弹窗和剪贴板使用测试替身，不修改使用者的剪贴板。
- `npm run check:silent` 包含工具箱无窗口测试及既有页面和截图回归。实测跨电脑网络发现、Windows 防火墙权限与不同网络环境仍需在两台物理电脑上验证；同机双实例不替代这些验收。

### 头像、证件照与实时预览

- 分类为通用处理、头像裁剪、证件照尺寸，各分类独立保留参数；每张图片独立保留头像和证件照构图。
- 头像支持方形、透明圆形 PNG，以及 128、256、512、1024 像素。证件照提供小一寸 22×32、一寸 25×35、小二寸 33×48、二寸 35×49 mm，按 300 DPI 换算像素；PNG/JPG 写入打印密度，WebP 仅保留像素尺寸。
- 拖动裁剪画面、方向键移动、加减键或滑块缩放，重置恢复居中。快捷尺寸允许放大，原图过小时清晰度会降低。
- 导入和切图自动预览，参数停止变化 200 毫秒后更新编码结果和文件大小；更新期间保留旧画面并标明更新中。裁剪画面即时绘制，导出与预览使用相同合成逻辑。
- 切换图片时只显示当前所选图片，原图准备好后才开放裁剪。预览缓存当前原图与水印，复用 Worker 中的解码结果；调整参数不重复读取原图，切图、移除和关闭页面时释放对应资源。重新处理或导出仍重新读取并校验文件，预览失败后的重试会刷新缓存。
- 不提供自动抠图、底色替换、美颜或打印排版，不依赖人物模型或在线服务。JPG 背景只填充透明区域，不替换照片原背景。
